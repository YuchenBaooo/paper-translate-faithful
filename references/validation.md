# 验证记录与效果边界

版本 2.0.0；记录日期 2026-10-25。

## 行为测试

21 个回归测试函数通过：10 个原位流程，11 个阅读辅助工具。覆盖发布门槛、源译与资产绑定、遗漏/重复/数字错误、字体冲突与冻结、保护区、过期合同/审校、中文标点、超宽数学拒绝、CMEX 轮廓、文献续行/半行裁切拒绝、图字 mask 保护、压缩等价/超时/启动失败回退。测试包含合成真值和真实论文节选，不等同于全篇语义准确率。

## 真实案例

Cox 等 Structured Light in Turbulence（2021）：原文 21 页，原位中文 21 页，阅读优化版 19 页。论文专用作业记录 246 个正文源块、320 个显示公式之外的数学片段、2570 个原数学字形检查、编号式(1)–(36)及未编号矢量基、14 幅图、1 张表、239 条文献。登记的技术检查无未解决项。原文与阅读版重新分页，不能按相同页码推定内容完全一致。

论文专用压缩从 44,707,455 字节降至 9,783,466 字节；19 页在 2× 渲染下逐页变化像素为 0，文本和目录一致。这些是单篇作业记录，不是通用 readerflow 重新生成全文的承诺。

本仓库的可运行教学节选包含 23 个单元、22 个原生资产；实际生成 1 页，检查 157 个原数学字形，通过技术门槛并已查看整页和局部。初始审校保持 pending，不能直接发布成品。新压缩工具在该教学输出上从 28,067,914 降至 5,151,714 字节，像素、文本和目录检查一致。

## 环境与限制

实测 Python 3.14.6、PyMuPDF 1.28.2、numpy 2.5.3、Pillow 12.3.0、fontTools 4.63.0；中文采用本机实际存在的 Regular/Bold 字体，不分发字体文件。基础配置兼容其他本机字体路径，但须重新核对。

本次辅助工具测试和复核为串行实施。可选 OCR/外部排版引擎的真实模型运行不在本次验证范围。复杂扫描、旋转/套栏、跨页大表、模糊图字仍需代表页试验及专门处理。数学资产保真、像素相等不能证明所有识别和科学语义无误。

没有独立记录每篇论文的模型输入/输出账单；当前不能报告可靠的平均 Token 消耗，详见 README 的统计口径。
