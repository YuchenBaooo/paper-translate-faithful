# 阅读重排：从问题到可验证成品

适用于已授权阅读优化的任务；入口的原位流程仍单独保留。工具只执行经核对的内容和对象合同，不会自动完成论文识别、全文翻译或语义审查。

## 诊断与经验

| 现象 | 机制 | 修正与验证 |
|---|---|---|
| 汉字间长空格、句中大片空洞 | 把英文词/数学片段的旧槽位分别固定 | 重建完整语义段落，公式作为原子随句流动；只对适宜的正文行有限两端调整，末行不拉伸 |
| 行距忽大忽小、公式基线不齐 | 固定行高、把数学名义 bbox 当墨迹 | 按每行实际数学 ascent/descent 留净空；正文、图注分别设置 leading，不缩公式凑行 |
| 多出邻近符号、变量上下标分离 | 用 bbox 并集推断一个公式，或把提取块当语义单位 | 显式声明有序片段及基线；核对上下文。相交不代表同一表达式，不能按相交传递合并 |
| 括号/根号缺失 | CMEX 控制字符、字形度量与实际轮廓不一致 | 嵌入字体 glyph ID + outline bounds 辅助定位，查看实际裁图；必要时原内容流级修复，禁止硬编码某论文的字体资源号 |
| 公式附近文字、条件、编号重叠 | 整块裁图带入相邻正文或旧编号 | 数学本体、条件词、编号分别登记；条件词翻译后组合，编号只放一次；找不到净空则另行留空间 |
| 标题孤悬、图注跨栏、结尾参考文献稀疏 | 只按对象出现顺序强行分页 | 标题随下一内容、段尾至少两行、引导句随公式、图注随图；参考文献按完整条目排、末页可按条目平衡 |
| 图中文字出现白底补丁 | 深色渐变背景采用白矩形覆盖 | 审过的字形 mask + 局部背景恢复，单独放中文层；保护科学内容，检查局部视觉及编辑区外像素 |
| 字体压缩卡住、留下空文件 | 子集化后 `garbage=4` 重复流比较代价高 | 可选子进程限时，`garbage=1`；逐页像素、文本、目录相同且更小才采用，否则复制已验收输入 |

减少空白不能靠删除内容、缩字或把全文拉伸铺满页面。章节结束、公式净空和图表留白有意义，不能统一清除。

## 工具与执行顺序

先用 `paperflow.py doctor` 探测；原位只需基础 requirements，阅读辅助依赖见 `requirements-reader.txt`。缺工具先报告真实能力，不自动下载大模型。所有命令从技能目录执行；任务输出放技能目录外，路径含空格时加引号。

1. **冻结与清点**：复用经过核对的源文件、逐页单元、术语和译文。另列公式、图/图注、表/表题、标签、脚注、参考文献、作者简介清单；写明原位问题及重排授权。不得把某次提取的段落数写成通用数量。
2. **建立片段**：按 `reader-plan.md` 准备 `assets-spec.json`，每个片段有源哈希、页码、裁切框、用途和 clean-clip 证据。执行：

```text
python scripts/vector_assets.py glyph-bounds SOURCE.pdf --page 3 --output glyphs.json
python scripts/vector_assets.py compose assets-spec.json ASSET_JOB
python scripts/reference_rows.py reference-regions.json references-proposal.json
python scripts/raster_label_patch.py label-patch.json LABEL_JOB
```

`glyph-bounds` 支持常规嵌入 CFF/TTF/OTF 的水平字形；旋转、非标准 FontMatrix、缺字体明确记录 unsupported。轮廓范围不证明裁切链、遮挡或非文字笔画可见。`reference_rows` 从审过的列区域按 `[n]` 提出条目边界，须再核对作者、题名、续行与顺序；不适用未编号/作者年格式时自行按真实条目建片段。标签工具产物始终是 candidate，需真实看图后再组入图资产。

3. **建立 reader 合同**：按内容语义重建连续段落，每个可见源单元恰好交付一次。`{{asset:ID}}` 携带原生数学片段；不用 TeX/OCR 重打已有数学。字体按本次约束配置，章节角色不能全当 body。阅读版的公式本体保持原大小；图表如需适栏缩放须已获任务授权并逐项检查可读性（不允许则 `fit:false`）。
4. **代表页试排，再全文**：

```text
python scripts/readerflow.py render reader-plan.json READER_JOB
python scripts/readerflow.py audit READER_JOB
```

生成 `candidate.pdf`、所有页 PNG、定位清单、冻结输入合同、技术 audit、待填 review。渲染不会自动填 pass。修改 plan、图资产或字体，另建新候选，旧审校不复用。重点查看首页标题/摘要/关键词、最密正文、最长行内公式、独立公式、复杂图、表格、文献和简介。新缺陷用最小片段复现，修正根因后再扩展。
5. **真实审校并发布**：按 review.md 对每个单元填写意义、数字、结构及证据；查看所有候选页，将确切候选哈希、审查方法、页码、可读性、未解决项写入 `review.json`。阅读自动门槛核对源单元绑定、公式资产次数、字形位置、越界、对象重叠、行首标点和标题后续内容；它不自动判断图字译得对、所有字体角色正确或视觉美观。

```text
python scripts/readerflow.py publish READER_JOB 中文_阅读优化版.pdf
python scripts/pdf_compact.py 中文_阅读优化版.pdf 中文_阅读优化版_精简.pdf --timeout 60 --scale 2
```

压缩为可选最后一步，不能覆盖已验收文件。成功时保留源/输出哈希和每页等价报告，审校通过的是输入，压缩输出由等价报告关联；失败/超时采用输入的原字节副本。像素相等只在记录的渲染倍率下成立，不声称数学上对所有渲染器等价。`--timeout` 限制子集化 worker，比较阶段逐页执行，不属于该计时。

## 备选与退出

无可靠数学片段时回到原页对象/可信 TeX 辅助定位；不能以近似重打绕过缺失。当前通用 reader 只支持一/双栏、水平文字、普通图表浮动与编号文献；旋转、跨页大表、复杂套栏需专门实现或已验证的外部引擎。不能为了使用本工具删掉不支持的内容。最多三轮针对性修复后同类失败，保留证据并换路线；对真正未解决内容明确交付候选状态。
