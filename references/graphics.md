# 公式、图片和表格的独立处理

## 公式

原始数学对象是内容真值。独立公式、行内公式、希腊字母、指标/上下标、单位和编号单独登记保护区。将它们与正文框分离；若混合，native 渲染器应拒绝重叠，不能扩大涂销框。保留区前后渲染像素一致是必要证据；对扫描公式也只保留原像素，不根据 OCR 猜公式。数学表达式中的自然语言如 “where” 单独翻译，不能当公式一起冻结。

阅读模式可以移动原生数学对象，其字形、尺寸和内部相对位置仍应保持。先审查明确的语义片段，再用 `vector_assets.py` 拼接；不要把跨行表达式的外接框或所有相交数学 bbox 并成一块。实际源可能把 C²/n 拆成块，须根据原图合成完整量；CMEX 大括号须用嵌入 glyph ID 的实际轮廓定位。原内容流级修复可作备选，但不得把某论文 xref/字体资源号当通用算法。字体轮廓工具报告 unsupported 时不能猜测成功。字形比较允许记录的浮点误差（字号 .002pt，origin .04pt），不能把序列化末位变化误报为缺字；容差也不能掩盖实际缺少的符号。

## 图内标签

逐项登记 `page`、`bbox`、`source`、`translation`、`role: figure_label`、`kind` 以及子图/标签关系。数字、刻度、a/b/c、模型名和变量按分类保留。图标题、图注和图内文字是三种对象，不能只翻图注就记整图完成。

- `kind: text`：标签存在原文字层。小范围 text-only redaction，保留 image 和 vector 参数；任何保护区/其他单元相交则停止。
- `kind: raster_label`：文字嵌在图像像素中；必须有 `background_rgb` 与明确的 `background_reviewed: true`，证据确认文字底色均匀且遮罩不穿曲线/箭头/数据。只对核对过的文字像素范围覆盖并放中文，不删除整张底图。
- 复杂背景：原位 native 不支持自动修图。可用 `raster_label_patch.py` 对审过的旧字形 mask 做局部背景恢复，再放中文层；或用来源明确的局部修补图/矢量文字层。必须实际查看，外部 stage 时完整登记改动区域。工具不能推断正确 mask，编辑区外像素 0 也不能证明编辑区内没误删曲线。无法安全替换则未解决；不得只补图例却宣称原位文字翻译。

本技能不使用整页生图重绘论文；显微图、散点、曲线等科学内容不能被生成式重画。用户要“准确且精准对齐”时，近似重建不是备选通过条件。

## 表格

单元格 ID 稳定；`table_id`、`row`、`col`、`rowspan`、`colspan` 记录合并关系。把可译单元格、纯数据、公式分开；单元格 bbox 在原单元格内部，线框不在写入区域里。表头、图例、单位和脚注上下文必须同看。首行/末行与跨页续表要检查，不能仅比较行数。

审核数字与对应行列的绑定，不只比较数字总量。禁止把原多线表改为三线表，禁止重采样原表图片。对于图片型表格，同样需要标签定位、底图保护与图内文字翻译。
